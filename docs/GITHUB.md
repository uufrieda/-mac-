# GitHub 发布信息

建议仓库名：`shefirst`

建议描述：女性指代优先的 macOS 简体拼音输入法。

Topic：

```text
shenicest-fission
```

说明：GitHub topic 不带 `#` 存储，页面上显示为 `shenicest-fission`。

## 推送到 GitHub

先在 GitHub 创建一个空仓库，例如：

```text
https://github.com/YOUR_NAME/shefirst
```

然后在本地仓库目录运行：

```bash
git remote add origin git@github.com:YOUR_NAME/shefirst.git
git push -u origin main
```

如果使用 HTTPS：

```bash
git remote add origin https://github.com/YOUR_NAME/shefirst.git
git push -u origin main
```

推送后，在仓库页面右侧 About 区域点击设置按钮，把 Topics 设置为：

```text
shenicest-fission
```
