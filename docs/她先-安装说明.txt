《她先》女性优先输入法 1.1.0

请使用“她先-1.1.0.pkg”。可以直接覆盖安装旧版本。

系统要求
- macOS 13.0 或更高版本
- 支持 Intel 芯片与 Apple 芯片 Mac

安装
1. 双击“她先-1.1.0.pkg”。
2. 按安装器提示继续，并输入 Mac 管理员密码。
3. 安装完成后，点击菜单栏输入法图标，选择“她先”。
4. 如果菜单里暂时没有“她先”，请退出当前 Mac 账户并重新登录；然后打开“系统设置 > 键盘 > 输入法”，点击“编辑”和“+”，添加“她先”。

首次打开提示
这是本机制作、尚未使用 Apple Developer ID 公证的安装包。如果 macOS 阻止打开，请按住 Control 键点击安装包并选择“打开”；也可以前往“系统设置 > 隐私与安全性”，点击“仍要打开”。

输入模式与设置
- 她先：性别未知时，女性形式排在第一位。
- 中性：性别未知时，优先使用“TA”或“对方”。
- 常规：恢复普通拼音候选顺序。
- 职业联想和褒义联想可以分别开关。

按 Control + ` 或 F4 打开“她先设置”。

“他”和“他们”仍保留在后续候选中；“其他”“吉他”等不是人物代词的词不会被错误替换。出现“爸爸、丈夫、男士”等明确男性信息时仍使用“他”。个人选词和转换均保存在本机。

关于语音输入
macOS 系统听写不会把识别结果交给第三方输入法处理。为了避免后台监听以及额外申请麦克风、辅助功能权限，1.1.0 不会自动改写系统听写已经输出的文字。

卸载
1. 在访达中选择“前往 > 前往文件夹”。
2. 输入 /Library/Input Methods
3. 将“她先.app”移到废纸篓，然后退出账户并重新登录。
